# K3-1 negative-space fixture contract

`input_contract_v1.json` pins `k3-negative-space/1.0.0` under KYD-134 before
implementation. `Finding` accepts already evaluated, cited judge/F1/F2 inputs;
`interpret` keeps exposure, knowledge, conclusion, defeat and measurement
separate and derives the effective obstruction state. A targeted protection
keeps the original adverse conclusion and its fact references. Missing
coverage or an unadmitted binding produces a named unavailable state. No rate,
weight or astrology is computed. Unknown release is a valid result.

The only writer entry is the explicitly selected
`ctx.config['negative_space_fixture_inputs']` list. It requires the build's
`kala_layer_candidate` to be `building` with `conventions.fixture=true`; all
inputs must name that chart and generation. The candidate is locked before
replacement, and a published or retained generation is refused. Empty results
replace only that private candidate partition. The legacy writer and its Swiss
backend guard remain the default dispatch. The old trigger composition shim
remains callable until K4-2b.

Migration 1343 adds only nullable metadata columns and a CHECK restricted to
this contract version. Legacy NOT NULL score/type/severity slots are filled
with inert zero/mild/malefic_transit compatibility values; the typed assertion
is the meaning of a candidate row. These slots are never read by the new
consumer. Migration 1338 already provides the five separate axis columns.

Consumer fixture tests do not prove a live judge binding, the four surviving
trigger mechanisms, or real output acceptance. The conductor still owes
explicit source, field, state, coverage and locator maps plus doctrine
admission. The survivor roster is deliberately absent in the artifact.
`kala_trigger.negative_space.unavailable_trigger` returns the named unqualified
boundary for a requested mechanism; it does not run or bless a legacy detector.
Frozen judge and WriterBase contracts, legacy/published data, upstream
completion and deployment/readback requirements remain in force.
