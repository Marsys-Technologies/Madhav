`run_heavy_writer_standalone.py` pattern verbatim: committed

asset_throughput, validates every target at build time, and returns the R-1..R-6
build record as `WriterResult.notes` JSON — capture that notes JSON into the

## 4. Rollback (refuse-unless-verified; exact preimage)

Rollback restores **from the §1 snapshot table** (the native's own write).
The rebuild is per-chart scoped (DELETE WHERE chart_id … + INSERT inside one
orchestrator transaction), so a failed build rolls back atomically and the
prior partition is untouched; the coverage gate additionally refuses to
replace the partition on incomplete event-class coverage. If a completed
rebuild must be reversed, run the block below with THIS run's snapshot table
name and the count/digest recorded in §1. The block REFUSES — before any
DELETE — when the snapshot table is absent, carries another chart's rows, or
does not match the recorded count/digest (stale or incomplete); it then
restores the exact preimage (all columns, ids included) and re-verifies the
restored partition against the same recorded pair. Any RAISE leaves the
partition untouched (the transaction aborts).

```sql
BEGIN;
DO $rollback$
DECLARE
  snap_count BIGINT;
  snap_digest TEXT;
  foreign_rows BIGINT;
BEGIN
  IF to_regclass('gochara_resonance_map_snap_482012f1_20260930000000') IS NULL THEN
    RAISE EXCEPTION 'ROLLBACK REFUSED: snapshot table gochara_resonance_map_snap_482012f1_20260930000000 is absent';
  END IF;
  SELECT COUNT(*) INTO foreign_rows FROM gochara_resonance_map_snap_482012f1_20260930000000 WHERE chart_id <> '482012f1-710e-4a25-994a-93821f5871aa';
  IF foreign_rows <> 0 THEN
    RAISE EXCEPTION 'ROLLBACK REFUSED: snapshot gochara_resonance_map_snap_482012f1_20260930000000 carries % rows of another chart', foreign_rows;
  END IF;
  SELECT COUNT(*),
         COALESCE(md5(string_agg(concat_ws('|', event_class, target_type, target_ref, weight::text, coalesce(classical_citation, '<null>'), uncited_extension::text, coalesce(source_rule_id::text, '<null>'), coalesce(target_resolution_state, '<null>'), coalesce(target_qualifier, '<null>')), E'\n' ORDER BY concat_ws('|', event_class, target_type, target_ref, weight::text, coalesce(classical_citation, '<null>'), uncited_extension::text, coalesce(source_rule_id::text, '<null>'), coalesce(target_resolution_state, '<null>'), coalesce(target_qualifier, '<null>')))), 'empty')
    INTO snap_count, snap_digest
    FROM gochara_resonance_map_snap_482012f1_20260930000000 WHERE chart_id = '482012f1-710e-4a25-994a-93821f5871aa';
  IF snap_count <> 177 OR snap_digest <> '00000000000000000000000000000000' THEN
    RAISE EXCEPTION 'ROLLBACK REFUSED: snapshot gochara_resonance_map_snap_482012f1_20260930000000 is stale or incomplete (count % digest % vs recorded 177 00000000000000000000000000000000)', snap_count, snap_digest;
  END IF;
  DELETE FROM gochara_resonance_map WHERE chart_id = '482012f1-710e-4a25-994a-93821f5871aa';
  INSERT INTO gochara_resonance_map SELECT * FROM gochara_resonance_map_snap_482012f1_20260930000000 WHERE chart_id = '482012f1-710e-4a25-994a-93821f5871aa';
  SELECT COUNT(*),
         COALESCE(md5(string_agg(concat_ws('|', event_class, target_type, target_ref, weight::text, coalesce(classical_citation, '<null>'), uncited_extension::text, coalesce(source_rule_id::text, '<null>'), coalesce(target_resolution_state, '<null>'), coalesce(target_qualifier, '<null>')), E'\n' ORDER BY concat_ws('|', event_class, target_type, target_ref, weight::text, coalesce(classical_citation, '<null>'), uncited_extension::text, coalesce(source_rule_id::text, '<null>'), coalesce(target_resolution_state, '<null>'), coalesce(target_qualifier, '<null>')))), 'empty')
    INTO snap_count, snap_digest
    FROM gochara_resonance_map WHERE chart_id = '482012f1-710e-4a25-994a-93821f5871aa';
  IF snap_count <> 177 OR snap_digest <> '00000000000000000000000000000000' THEN
    RAISE EXCEPTION 'ROLLBACK FAILED VERIFICATION: restored count % digest % vs recorded 177 00000000000000000000000000000000', snap_count, snap_digest;
  END IF;
END
$rollback$;
COMMIT;
```

Then confirm, read-only: the live partition digest equals the recorded
pre-rebuild pair (`SELECT COUNT(*) AS row_count,` … as in §1), and that
another chart's partition is unchanged (take its digest before and after
with the same statement, substituting its chart_id).

Restoring the snapshot restores the PRE-WP3c (dishonest) rows — rollback is a
pause for diagnosis, never the end state. The fix direction is always data
forward, never a weakened guard. Drop the snapshot table only after the
rebuilt map has soaked.
