# §1 Mission

Operator named the gap (CHAT_V2_SURFACE_AUDIT §5.1): the streaming-state indicator in V2 is a 2-pixel gold blinking caret (`chat-stream-caret` class). It's so subtle the operator didn't perceive it. Wants a 3-dot blinking indicator instead — the canonical "Thinking..." pattern from ChatGPT/Gemini/Grok.

The component already exists at `platform/src/components/chat/StreamingDots.tsx` (preserved by α stream from the V1 cleanup). It renders 3 dots animating via the `@keyframes chat-dot` CSS animation with staggered delays (`-0.24s`, `-0.12s`, `0s`) for a wave effect.

This stream replaces the `chat-stream-caret` class on the chat-prose div in `MarkdownContent.tsx` with an inline `<StreamingDots />` element rendered when `streaming === true`. Placed at end of the prose div so it trails the last streamed word.

```tsx
import { cn } from '@/lib/utils'

export function MarkdownContent({ children: rawChildren, streaming, className, ...rest }: Props) {

        rehypePlugins={[rehypeKatex]}

      >
```

**Target:**

```tsx
import { cn } from '@/lib/utils'
import { StreamingDots } from './StreamingDots'
// ... other imports ...

export function MarkdownContent({ children: rawChildren, streaming, className, ...rest }: Props) {
  const components = useMemo(() => MARKDOWN_COMPONENTS(streaming), [streaming])

  return (
    <div
      aria-live={streaming ? 'polite' : 'off'}
      aria-atomic="false"
      aria-busy={streaming}
      className={cn(
        'chat-prose text-[15px] leading-[1.72] text-foreground',
        '[&>*:first-child]:mt-0 [&>*:last-child]:mb-0',
        className
      )}
      style={streaming ? { contain: 'style' } : undefined}
    >
      <Streamdown
        remarkPlugins={[remarkGfm, remarkMath]}
        rehypePlugins={[rehypeKatex]}
        components={components}
        isAnimating={streaming}
      >
        {/* Streamdown body ... */}
      </Streamdown>
      {streaming && (
        <span className="inline-flex items-center ml-1" data-testid="v2-streaming-dots">
          <StreamingDots />
        </span>
      )}
    </div>
  )
}
```

Notes:

- Drop `streaming && 'chat-stream-caret'` from the className.
- Add import for `StreamingDots`.
- Render `<StreamingDots />` after `<Streamdown>` (inside the same prose div) wrapped in an `<span className="inline-flex items-center ml-1">` for inline placement at the end of the last block.
- `data-testid="v2-streaming-dots"` for future smoke spec assertion.

The placement after `</Streamdown>` (rather than INSIDE Streamdown's rendered content) means the dots appear after the last paragraph rather than inline with the last word. This is the standard ChatGPT/Gemini pattern. If operator wants TRUE inline-with-last-character placement, that requires deeper streamdown integration (out of scope).
