```bash

  find platform -name "${c}.test.*" -o -name "${c}.spec.*" 2>/dev/null \

# Phase 3 — grep-and-clean residual JSDoc references
# For each deleted component name, grep recursively. May find references in

# // see comment that no longer points anywhere meaningful).
```
