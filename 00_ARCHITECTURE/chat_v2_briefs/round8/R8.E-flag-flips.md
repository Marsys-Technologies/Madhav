# §1 Mission

The surface audit identified 5+ feature flags whose code paths exist but default to OFF, leaving capabilities dormant in production. This stream:

1. **Flips HISTORY_COMPRESSION_ENABLED** — low-risk, behind-the-scenes optimization that compresses conversations > 32k tokens before synthesis. Reduces cost + latency for long chats. No user-facing UX change. Operator-authorized for direct flip.

2. **Deletes MANIFEST_BUILDER_ENABLED** — dead flag (no consumers anywhere in source). Removes from `FeatureFlag` union + `DEFAULT_FLAGS` block.

3. **Authors CHAT_V2_FLAG_AUDIT_v1_0.md** — analysis-only document for the remaining dormant flags with per-flag recommendations. Operator decides which to flip in a follow-up.
