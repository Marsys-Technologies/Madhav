# Who reads a NODE's dignity or strength rank in Pravāha's Gochara code — and what changes under N-82

## Bottom line
**No Gochara code path today computes a number from a node's dignity or a node's strength rank.** The only live, value-returning read of a node's dignity is **L1's classifier**, reached by Pravāha **only through PR #2914's strict wrapper (not yet merged)**; everything else is declared-but-unimplemented (all-NULL milestone), node-excluded by citation, or never reads dignity at all. What N-82 changes for us is **one string on one path** (the null, instead of L1's friend/enemy/neutral label for a node in a non-exaltation sign) and **one housekeeping removal** (a Pravāha-local dignity table that shadows L1's).
