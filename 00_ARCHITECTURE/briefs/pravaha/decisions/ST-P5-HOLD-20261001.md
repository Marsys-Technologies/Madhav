# ST-P5-HOLD-20261001 — P5 tier withheld

**AM-7's P5 contract lands** (draft `GOCHARA_SPECS_V1_5_AMENDMENTS_DRAFT` §AM-7: form identity,
applicability, typed operand lineage, declaration read-back / O-BP-3).

**Disposition in AM-5 terms.** For every P5 rule-path version and every event class, the search-
inventory pin is

| field | value |
|---|---|

contract has landed. P5 is then `included` in a **new generation** (a sealed generation is never
reopened).
