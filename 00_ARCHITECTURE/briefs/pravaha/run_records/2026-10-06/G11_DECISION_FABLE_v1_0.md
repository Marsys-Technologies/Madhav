# G11 near-miss decision memo — Fable 5.1, 2026-10-05

Sources: origin/main `f72dc9d93`; branch `pr3143` (`bd9dc966d`); S = `design/GOCHARA_DESIGN_SPECS_v1_4.md`; EP = `measurement/EVALUATION_PROTOCOL_v2_3.md`; kernel = `platform/python-sidecar/services/gochara_kernel/`. Read-only; nothing run.

**DECISION.** Store near-misses as their own kind, `near_miss`, in their own tables with their own ordinal space, so no contact id can move. Attach them to classes as relationship records whose `operator_role` a DB CHECK forces to `testimony`: their geometry (closest approach, kernel peak) is visible data, never weight. Serve them as a separate, labelled "threshold" layer beside contact windows. Promote to a scored *support-only* tier only through the existing B5.4-ablation / L5-calibration gate under a new `rule_version`. I read the ruling as R2 — a near-miss *is* the sandhi-like state — not R1 ("counts only when it falls at a rāśi/nakṣatra/daśā junction"): the "so the dignity … is not equal" clause follows from R2, and R1 would keep about 2 of the 24 (the two on natal Mercury 270.84°, the only point within 1° of a cusp). R1 is open question 1.

## 1. Representation

- **Identity.** `near_miss_id = hash(physical_object_id | "near_miss" | orb_deg | k)` — same digest scheme as contacts (substrate.py:46-51, 136-139), distinct literal token, orb in the bytes because the kind exists only relative to the band (a crossing does not). `k` = 1-based ordinal over the full-domain near-misses of one physical object ordered by `t_nearest`, append-only exactly like contacts (substrate.py:142-163). The contact ordinal list — over exact roots only (record_store.py:264-266) — is untouched; a contact row stays what it is today. AM-25's "stay" (AM25 §4 item 1) is the same object, but its `hash(…,"no_root",t_in)` is rejected: a timestamp in identity is what §6.1 forbids (S:618-621; substrate.py:30-33).
- **Own tables, not a kind column.** `ka_gochara_near_miss_identity` (global insert-only, mirroring 1153:813-830) and `ka_gochara_near_miss` (chart/generation-scoped). Reasons: the contact table's whole constraint family encodes "exact instant unless truncated" — kgc_t_exact_iff_truncated_ck, kgc_truncated_method_ck, kgc_t_out_unless_truncated_ck, kgc_exact_precision_ck, kgc_time_order_ck (1153:1085-1098); its FK into the contact ordinal space (1153:1062) would force a near-miss into that space; and the certifier reads every `ka_gochara_contact` row as a contact (contact_certify.py:119-125) and would call it invented.
- **Fields.** body, relation_kind, physical_object_id, convention_id, orb_deg, ordinal, t_in, t_out, **t_nearest** (defining instant), **closest_approach_deg**, **station_event_id** FK → `ka_gochara_sky_event` with event_kind='station' (substrate.py:527-546; NOT NULL unless truncated), solver_method/delta_lambda/delta_t/precision_regime, coverage `{truncated, decided_from_whole_stretch}`. CHECKs: `t_in < t_nearest < t_out`; `0.005 ≤ closest_approach_deg < orb_deg`; station instant inside the stretch. Peak strength is derived, `1 − d/orb` (gochara_rules/kernel_factor.py:133-134), never stored as a second number (§N.7 item 3).
- **Definition (ephemeris-decidable).** A maximal in-band stretch of one ray level whose signed distance has no zero anywhere in the *whole* stretch (followed beyond a clipping horizon, pr3143 contact_certify.py:88-105, 136-142), proved by the speed-bound clearance |d₀|+|d₁| > VMAX·Δt bisected to 60 s (pr3143:70-85), with closest approach ≥ 5e-3° (pr3143:67). Within a 1° band exactly one reversal occurs (the orb is smaller than every retrograde arc of these bodies), so `t_nearest` is the stretch's unique station instant and d_min = |λ(station) − level| — already Swiss-refined (substrate.py:541-544). An exact tangency (d_min < 5e-3°, or any root) is a CONTACT, never a near-miss; the (1″, 18″) dead band is "unresolved stretch" → loud refusal (§N.8). Real chart: smallest d_min 0.139°, dead band empty. Horizon edge: decided from the whole stretch inside the convention domain (substrate.py:168-171); a stretch cut by the *domain* edge is stored `truncated` with t_nearest NULL when the station lies outside, as N3 contacts are.
- **Record link.** Nullable `near_miss_id` on `ka_gochara_relationship_record`; kgrr_transit_natal_ck (1155:575-581) becomes "exactly one of contact_id / near_miss_id"; new CHECK: `near_miss_id IS NOT NULL ⇒ operator_role='testimony' AND provenance='uncited_extension' AND ruling_ref IS NOT NULL` (Ruling 10). The sweep then excludes them by construction (window_sweep.py:759-760).
- **Checker.** Replace the interim sink (pr3143:185-199) with an unconditional both-ways comparison: every proved graze ↔ exactly one near_miss row (interval via boundary_match; d_min within accuracy; t_nearest compared in angle as at stations, contact_certify.py:29-30); no near_miss row without a proved graze; near_miss ∩ contact = ∅ per object; an unprovable stretch still raises. Window/record verifiers: windows byte-identical with near-miss records deleted (the O-RR-7 mutation, S:138-141).

## 2. Dignity

**Testimony-first, promotable.** (a) It is the project's standing treatment of every uncited practice element (S:57-67, 409-414). (b) The only non-invented number is the kernel's `1 − d/orb`, which at equal distance weights a near-miss *equal* to a contact — violating "not equal" — while any discount is an invented weight (B.10; AM25 §4 rejected exactly this). (c) The point orb defining the kind is itself unratified for scoring (window_sweep.py:30-32), so no grade can be earned yet. "Shown separately" is a serve-time projection: the connected union of a class's near-miss supports is a labelled near-miss window (kind facet, §N.6), never an `eval_window` row. Open a window alone? Phase 1 no — testimony never admits (S:61-62). Phase 2 (B5.4 Δ-median-rank or L5 calibration; new rule_version; generation 5.x): scored support-only — may extend a component holding ≥1 contact-rooted member, never form one; any dignity factor enters with `calibration_status=calibrated` only (S:173-178). Classical basis, honestly: [P] practice holds stationary/retrograde planets intensified; Ṣaḍbala's cheṣṭā-bala grades vakra and vikala (stationary) differently and must be read before citing [U]; the served gochara doctrine is sign-based; I know no served verse treating approach-without-exactness as a result-giver. "Lower dignity" is therefore as defensible as "strong station" — both practice, under Ruling 10.

## 3. Name

"Sandhi" fits as the owner's category (a liminal state), not as the stored token: here sandhi already means a partition junction — brahmagyan/gandanta.py:2 ("water→fire sandhi"), migration 876 `sandhi_flag`, `kala_dasha_sandhi_get`. Stored kind `near_miss`; display "near-miss (sandhi-class; practice, Ruling 10)". Any Sanskrit coinage must be marked coined.

## 4. Scoring

Phase 1 changes nothing in the candidate set, T-cover, T-time, T-rank, T-FP: testimony rows are not members (window_sweep.py:759-760), so the admitted day-fraction (EP:189-206) and dedup set (EP:126-130) are unchanged — the 99.87 % mode cannot recur from this. That is the ablation evidence the promotion gate needs (S:409-414). Phase 2 support-only bounds inflation to days abutting existing windows and adds no candidates (abutting merges, EP:126-128).
