Version: 1.0. Status: ACTIVE. Changelog 2026-10-16: D-OWNER-TESTS-20261016 replaces the review-directory placeholder with the campaign review template.

[Authoritative testing standard](../DECISION_TESTING_STANDARD_v1_0.md) applies to every review and step receipt, including bootstrap and packet exits. The reviewer, not the author, writes the complete distinct-production-claim list from the brief, packet and cited classical rules into the verdict.

For each claim record:

| Claim and brief/packet/classical citation | Doctrine-grounded oracle and classical source (B.3/B.10) | Pinned merged head, passing command/exit | Single planted reversion, failing command/exit and job-copy path |
|---|---|---|---|
| Reviewer-enumerated claim | Source-cited expectation, never captured current output | Exact head and observed exit 0 | At most one planted reversion per claim; observed nonzero exit |

Report all real defects together and fix them regardless; each fixed finding has a passing fixed-tree / failing reverted-copy proof. A surviving reversion that is an already-covered variant or changes no production behaviour is non_blocking and never blocks MET. No combinatorial variants or per-mutant oracle requests. One bounded review round; non_blocking findings never trigger another; a second only for a BLOCKING finding.

Existing receipt JSON shapes are unchanged. `mutation_verified:true` attests every enumerated claim's reversion failed at the pinned merged head and real defects were fixed. A receipt is materialized only from the independently verified, hash-bound verdict; this template is not itself evidence. N.8, N.7.6, SR-A4-01, A1 and personal-data handling remain unchanged.
