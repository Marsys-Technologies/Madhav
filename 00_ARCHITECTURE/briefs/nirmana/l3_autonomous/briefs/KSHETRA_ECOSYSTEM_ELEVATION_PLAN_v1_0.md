## §0 — One page

Kshetra models a continuous hazard λ(t) per life-event class as
`ln λ = ln λ⁰ + ln P̃ + Σ clock + Σ β·x + Σ ln(1−ρu)`, stored as ~343k log-linear segments per class
with every term retained per segment. It is the only Kāla asset that emits a **shape over time**
(the Strategy §3 *Interval/trajectory segment*), and that uniquely serves **L3-Q06** — how a chapter
differs from the one before, by *mechanism composition*, which no window carries.

Its arithmetic is, against VA §10.2, **otherwise unusually clean** (raises on missing priors; pins its selections;
refuses confidence it has not earned; asserts provenance reconciles before writing). Its defects are
at the **seams, in publication — and in one place the brief itself got wrong**: the suppression
the stored field actually applies is chart-wide, not the route-scoped contract the code documents
(G3, §2 item 0); the tag that separates a calibrated hazard from a fabricated
one is computed and thrown away; the signed L2 mechanism becomes an unsigned conductance; σ_T is
read live from L4; the layer's own classical transit assets are re-derived or ignored; the
generation has never been published; L5 binds to it with an unordered `LIMIT 1`; and nothing serves it.

**The plan:** fix the seams by stage (S4 → S3 → S2 → S1 → S5), make the edge register true in both
directions, wire the layer's accepted classical assets *into* the covariate vector instead of
recomputing them, publish the calibrated 6-class configuration fresh at W7, give the field a reach
(U11) and give L5 a correct bind (U10) — and gate every model enrichment behind the one ablation
that decides whether the shape-over-time earns its cost.
