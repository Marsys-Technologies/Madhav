## §10 — Regression: what this packet made worse

### F-1 (§2) — a detected divergence can still be lost, on the uncaught-exception path. Measured.

### F-3 (non-blocking; belongs in the report) — the state class changed for this family

HEAD's `_terminalize_preflight_failure` wrote `state='aborted'`. A3 writes `state='error'`. The
project's own stated convention is at `platform/src/app/api/cockpit/watchdog/route.ts:138` —
*"'building' rows (judged dead) -> 'error'; 'queued' rows (never got a chance) -> 'aborted'"* — and
`AssetNode.tsx:53` maps `aborted → 'cancelled'`. By that convention a never-dispatched asset belongs
in `aborted`. A3 instead follows `_mark_asset_blocked`'s louder convention (*"state='error' … the
loud, surfaced state — red in the tracker, counted in the run's error tally"*), which I judge
**correct** — a registry divergence is a failure, not a cancellation, and showing it as "cancelled"
was the weaker signal. But it is a real, **undocumented** behaviour change: monitoring that filters
`state='aborted'` will stop seeing this family. The before-measurement's own query is state-agnostic
and keeps matching. `_terminalize_diverged_assets`'s docstring carefully preserves the *error-string*
prefix for monitoring and says nothing about the *state* change — it should say both.

### F-5 (accepted; belongs in the report) — `asset_throughput` is now written where it was not

Under HEAD a preflight abort touched `asset_throughput` not at all. A3 sets the diverged asset's row
to `state='error', last_built_at=NOW()`. If the divergence is a transient false positive — and the
before-measurement found both witnessed Family-A incidents to be transient — this downgrades a
possibly-`lit` asset to red in the cockpit and stomps its `last_built_at`. Deliberate, consistent
with the file's loud-over-silent convention, and the predicate fix targets the very false-positive
source that would trigger it. Stated, not charged.

Note the two directions together: **F-5 writes where HEAD wrote nothing; F-1 writes nothing where
HEAD wrote.** Both belong in the report.
