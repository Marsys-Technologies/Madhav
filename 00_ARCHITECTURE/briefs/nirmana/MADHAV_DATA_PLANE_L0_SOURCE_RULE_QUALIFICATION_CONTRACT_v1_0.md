# L0 source witness and rule qualification contract

## Separation of authority

| Surface | Epistemic role | Cannot establish alone |
|---|---|---|
| `bg_texts` / held corpus | work, edition, translation, chunk and evidenced rights testimony | executable operator or consensus |
| `bg_text_index`, `bg_compendium_index` | navigation and hydration candidates | exact passage authority |
| `bg_concordance` | related roots/schools and discovery | independent agreement, truth or probability |
| `bg_rules`, yoga/doṣa/method assets | extracted clauses, labels and candidates | chart occurrence or qualified scope without witness |
| source steward | admission of exact witness, edition/translation and existing rights/use status | source acquisition or rights expansion by execution |

A `QUALIFIED_EXECUTABLE` rule requires work, edition, translation, passage
locator, ancestry root and an already-evidenced admitted rights/use status, plus
method/school, operator, prerequisites, applicability, logic, exceptions,
cancellations and dispute. Extraction confidence remains extraction confidence.
Multiple representations of one ancestry root are correlated, not votes.

## Bhāvat Bhāvam adjudication

The repository holds a generic concept/glossary, a preserved implementation map
and a differently scoped KP extraction candidate. It does not hold an exact,
admitted passage + edition/translation + rights pin supporting the frozen
odd-house, non-recursive reference scope. Therefore:

- source passage ID is an explicit unresolved sentinel;
- current method and clause state is `UNQUALIFIED_SOURCE`;
- the readable KP candidate is `READABLE_NOT_EXECUTABLE`;
- even houses are `METHOD_INAPPLICABLE`;
- recursive, generator or primary-outranking requests are `UNSUPPORTED_SCOPE`;
- `QUALIFIED_EXECUTABLE` is in the vocabulary but the positive fixture is
  `NOT_REACHABLE` in this release.

This is a producer-ready honest gap, not doctrinal failure. Execution did not
select a convenient text, infer rights or broaden the map.

## Portfolio qualification boundaries

Dignity/combustion values remain named conflicting variants pending source and
meaning adjudication. Yoga, doṣa, daśā, KP, Praśna, Muhūrta, transit, Kota,
vedha/latta and remedy catalogs remain catalog/reference capital unless their
exact clause prerequisites are separately qualified. Sarvatobhadra remains
`EMPTY_BY_DESIGN` because its school/source conflict is unresolved. Citation
resolution and concordance remain navigation, never qualification.

Medical, vāstu and remedy testimony stays attributed, restricted and purpose
bound; it is not diagnosis, efficacy, individual probability or horizon
authorization. No source/right/safety authority changed.
