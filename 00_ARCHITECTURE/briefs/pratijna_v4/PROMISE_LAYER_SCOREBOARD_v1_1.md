## 0. What this is and isn't

This is the **first production verdict set in the project's history whose value was set by a
measured, ruled, classically-cited amendment** — not the original v4.0 rubric as ratified at the
2026-08-08 checkpoint, but that rubric plus AMENDMENT F1 (dispositor-conjunction exception),
adopted 2026-08-09 by ruling R22 on the evidence of `F1_SIDE_BY_SIDE_v1_0.md`. Every number below
was written by the real production writer (`bo_pratijna.py`, `engine_version=bo_pratijna_v4.1.0`)
against the real production database, re-run for this chart at F1 ADOPTION CYCLE Stage 2 and
verified live (see `F1_CYCLE_STATE.md`, adoption phase).

**Method, scope, and outcome-matching are unchanged from v1.0** — this is a re-scoring, not a
re-adjudication. No `life_events` match, category judgment, or verdict-basis text is revisited
here; §2/§3's "Lifetime outcome" / "Match basis" columns are copied verbatim from v1.0. Only the
`occurrence`/`condition`/`v4 status` columns and the classes' resulting verdicts (where a band
crossing changes the reading) are updated to their new v4.1.0 values. §4 (Derivation-link
resolution) is likewise unchanged in substance — the same provenance ids resolve, because the
amendment touches only §2.1's dignity band inputs, not the `chart_facts`/`chart_divisionals`
provenance chain any class's ledger cites.

**Timezone note (unchanged from v1.0):** `life_events.event_date` is UTC with an `18:30:00`
time-of-day convention = `00:00:00 IST` the *following* calendar day. All dates below are IST.

## 1. Method (unchanged from v1.0 — restated for a self-contained read)

Two evidence tiers, stated per class, never blended silently: **direct category/keyword match** and
**domain match**. Every class cites the exact `event_id`(s) it matched on. Where no row could be
honestly matched, the class is marked **no-outcome-data**. The one data-hygiene finding from v1.0
(a `[TEST FIXTURE]`-labeled `travel_event` row, excluded from that class's evidence) still applies
unchanged.

**This is the first production verdict in the project's history whose value was set by a measured,
ruled, classically-cited amendment**, not by the original v1.0-ratified rubric alone. The path from
v4.0's WEAK/0.321 to v4.1's MODERATE/0.450 was not a tuning pass against this chart's known
marriage outcome — it was: (1) a rule (AMENDMENT F1) authored and committed BLIND, before its
effect on any chart was computed (R20 item 1, `AMENDMENT_F1_SPEC_v1_0.md`'s own DISCLOSURE clause);
(2) measured side by side against v4.0 on both canonical charts with populated data
(`F1_SIDE_BY_SIDE_v1_0.md`); (3) adopted by an explicit ruling (R22, native + Fable, 2026-08-09) on
that evidence plus classical merit — not from a target number. The marriage cell happening to be
the amendment's one band-crossing effect on this chart is a genuine measured outcome of that
process, not a post-hoc justification for it: `F1_SIDE_BY_SIDE_v1_0.md` §3 traces marriage's
+0.129 shift to the same Venus-conjunct-Jupiter dispositor pair that also moves nine other classes
on this chart (bereavement, business_launch, career_setback, foreign_settlement, major_gain,
major_loss, property_acquisition, romantic_start, separation) — marriage is not a special case
inside the rule, only the one place among ten where the shift happened to cross a band edge.

**What the narrowed divergence plausibly means, stated as interpretation, clearly separated from
the measurement above:** v4.0's WEAK reading paired with a real marriage was flagged in v1.0 as "a
real, measured improvement in calibration direction" over the v3 predecessor's `DENIED` reading,
while still under-reading a chart that did produce a marriage. v4.1's MODERATE reading narrows that
gap further — "roughly half of the class's classical evidence set is present and aligned" (§6.1's
own plain-language band definition) is a closer qualitative match to an occurred marriage than
"occurrence is not supported as more-likely-than-not," though MODERATE is still not STRONG or
VERY_STRONG. Whether this counts as calibration improvement, a coincidence of this one chart's
Venus/Jupiter placement, or neither, was explicitly left to the native + Fable by
`F1_SIDE_BY_SIDE_v1_0.md` §5 and is not re-litigated here — this section reports the now-adopted,
now-production value, not a fresh adjudication of whether adopting it was correct.
