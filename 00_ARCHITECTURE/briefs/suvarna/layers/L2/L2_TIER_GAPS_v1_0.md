# L2 Bodha — tier gaps (Track A step 2)

This file records what the sealed tiers do **not** supply when the tier-3 template is filled for L2. It writes no
content into the holes: where a clause is missing, the instance (`L2_LAYER_INSTANCE_v1_0.md`) says
"TIER GAP: TG-L2-nnn" and stops. Nothing here certifies anything and no register row, ledger line or tier is edited.

**Reading rules.** A row is a gap only after the tier files were searched for a clause that supplies it (Part B lists
the clauses that *were* found, including three the earlier skeleton treated as inventions). "Register" names the
existing `NIKASHA_CHANGE_REGISTER_v2_0.md` row that already records the same hole; it is cited, not restated. Line
numbers are the checkout's (`2a78ec64d`). `Q1`–`Q7`, `G1`–`G2` are the read-only queries and git reads defined in
Part D; every figure in the evidence column is a census field, one of those reads, or a file:line.
