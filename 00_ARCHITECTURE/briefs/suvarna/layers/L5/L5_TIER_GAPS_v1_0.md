# L5 Mīmāṃsā — tier gaps

them, and the instance marks each hole `TIER GAP: TG-L5-nnn` instead of writing content. Before a row was written the
four tier files, the tier-2 companion register and the change register were searched for a clause that supplies the
content (search terms are in each row's evidence).
