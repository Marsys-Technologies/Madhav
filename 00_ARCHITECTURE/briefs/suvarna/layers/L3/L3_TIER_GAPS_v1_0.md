# L3 Kāla — tier gaps (A.L3i)

**What this file is.** One row per clause the L3 instance needed and the four tiers do not supply. It records; it
fills nothing and proposes no final text (a "remedy" column is the pointer a register row already carries, never a
drafted clause). A row is written only after the tier files were searched for a clause that supplies it (the
searches are named in the evidence cell). Where a clause supplies PART of what was needed, the row says which part
is supplied and which is not.

**How to read a row.** `clause` = the clause that failed to provide (file § line). `needed` = what the L3 draft
needed. `evidence` = the census field, query or file that shows the hole (figures are read from those, never typed
from memory). `tier` = the tier the remedy lives in (T1 product definition, T2 data plane, T3 layer template,
T4 asset template). `register` = an existing row in `NIKASHA_CHANGE_REGISTER_v2_0.md` that the gap duplicates
(cited, not restated); "NEW" = no register row found (searched by keyword, the search is in the evidence cell).
