# L0 — tier gaps (A.L0i)

**What this file is.** One row per clause the L0 layer instance needed and the four tiers did not supply. A gap is
*recorded*, never filled: the instance marks the section `TIER GAP: TG-L0-nnn` and carries whatever it carries from the
v3.0 draft with its provenance stated. Nothing here changes a tier, the register or a ledger.

**How a row was earned.** Before a row was written the four tier files were searched for the missing clause (terms
searched are named in the evidence cell where the negative result matters) and `NIKASHA_CHANGE_REGISTER_v2_0.md` was
searched for a row that already carries the gap. Where one does, the row cites it (column *Register*) and does not restate
the remedy. Evidence IDs (`CEN-*`, `Q-*`, `F-*`) resolve in the **Measurement register** at the end of
`L0_LAYER_INSTANCE_v3_1.md`; every figure below is read from the census JSON, the registry, a read-only query or a named
file at the inspector commit — none is typed from memory.
