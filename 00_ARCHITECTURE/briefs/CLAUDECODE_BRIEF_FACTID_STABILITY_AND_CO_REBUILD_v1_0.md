- `fact_id` is generated by `_fact_id(category, subject, key, chart_id, ayanamsha_id, build_id)` (`ga_writers/ga_structural_writer.py:621`) — a TEXT key (not random UUID) that is deterministic EXCEPT it includes `build_id`. So every new build → all-new fact_ids.
