# R5.3 CONTENT SPECS — what each failing answer must contain, section by section

**Universal spec (applies to all 16; violations here are why most floors failed):**
U-a. LEAD WITH THE VERDICT — first element states the answer plainly (graded term, not hedge-soup);
     evidence follows, never precedes.
U-b. EVERY claim-bearing row: epistemic grade + (where positional) the §31.4 time_sensitivity note.
U-c. ≥1 inline classical citation (verse ref + 12–30 word text) at interpretation intent; more only
     if each earns its place.
U-d. BOTH SIDES: at least one counter-signal/dissent row whenever the register holds one; its absence
     stated when it doesn't ("no significant contradiction on record").
U-e. Dates ALWAYS with ages; degrees as sign+deg-min+nakshatra-pada; strengths as grade+number.
U-f. Close with drill_pointers typed astrologically (the §28.4 vocabulary) — never generic "more".

## Q2 — entity assessments
**Q2-N-1 "How is my Saturn?" (graha_portrait):** verdict line = functional role for Aries lagna
(yogakaraka? no — 10L+11L; state it) + net condition in ONE sentence. Then: D1 dignity (exalted,
Libra H7) WITH the D9 debilitation tension explicitly narrated as promise-vs-delivery; shadbala
grade+rupas+pctl; 2 strongest avasthas BY NAME with one-line meaning; its 2 heaviest yogas w/
citation; current/next Saturn periods w/ ages; ego-net (top-3 edges). The D1×D9 tension IS the
answer's spine — a portrait that lists both without narrating the tension fails.
**Q2-A-1 "debilitated Jupiter really?" (A):** verdict = neecha + bhanga status FIRST (checked
conditions enumerated, formed-or-not, cited); then functional read (Jupiter as 9L/12L for Aries) in
the 10th — dignity vs bhava-utility distinguished (a debilitated graha in kendra ≠ a ruined house);
D9 state; one counter-consideration; NO remedy talk (not asked).
