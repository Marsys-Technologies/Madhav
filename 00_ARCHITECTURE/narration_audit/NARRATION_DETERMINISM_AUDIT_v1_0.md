# Narration Determinism Audit — v1.0

## The one-breath verdict

**Your core fear did not materialise: there is no LLM in the deterministic narration path.** All 12 surfaces were confirmed no-LLM — no model client is imported, no completion is called, nothing routes to a generative model. The narration engine is genuinely a function of facts, exactly as you conditioned your acceptance on.

**But "deterministic" and "correct" turned out to be two different guarantees — and the gap between them is where the defects live.** The Ṣaḍbala bug was not a one-off: it is a *class*, and the audit found it reproduced in the L2 root writer itself, plus 27 sibling defects of the same family (a value selected without disambiguation, a unit mislabelled, a grade compared against a hardcoded constant instead of the L1 fact, a contradiction warning that never reaches the page). None of these is an LLM leak. Every one is an untested derivation over correct, verified facts — the precise failure mode you caught by hand.

## Why this matters in one sentence

A fact being `two_pass_verified` guarantees the *number* is right; it never guaranteed the *sentence that picks among those numbers and grades them*. That sentence is what every finding below is about.

## The systemic pattern (read this before the table)

Two findings are **verdict-inverting** and they are the same bug in two places:

- **`registry_bridge.ts:3498`** — the serve-side Ṣaḍbala narration you already caught: `find()` on `fact_category` ignores `fact_key`, grabs the unitless `ratio` (1.20), labels it "rupas", subtracts a hardcoded 6.50, grades every planet "weak" on every chart.
- **`bo_laksana.py:831`** — the **same mis-selection inside the L2 root writer** (`_build_strength_lookup`), and *worse*: no `fact_key` filter **and no `ORDER BY`**, so it stores whichever of the `rupa`/`ratio` rows the database returns last. That is non-deterministic at the source — the grade a caller sees can change between two builds of the identical chart, and it feeds every downstream salience score and signature tier in Bodha.

The lesson generalises: **wherever a `fact_category` grew a second `fact_key` over time, every consumer that selects by category alone is a latent inversion.** The audit hunted exactly this across all 12 surfaces.
