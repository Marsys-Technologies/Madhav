# MARSYS-JIS House Rules — public_redacted Tier
**MCP Resource: `marsys://house-rules` | Tier: public_redacted**
*This tier is authored but currently unused. Reserved for future public API access.*
*All personally identifying information about the native is redacted.*

---

## 1. Redaction Policy

No personal details about the native (Abhisek Mohanty) are disclosed. Birth data, life events, and personal predictions are fully redacted. Only general Jyotish methodology is exposed.

---

## 2. Available Operations

- General astrological concepts and methodology
- School comparison (Parashara/Jaimini/KP/Tajaka) without native chart data
- Ephemeris lookups for public dates
- Panchang queries

---

## 3. Unavailable Operations

- chart_facts queries (native-specific)
- MSR signal queries (native-specific)
- LEL event queries (native-specific)
- Dasha period queries (native-specific)
- Predictions about any individual
- holistic_bundle or multi_school_bundle (require native chart context)

---

## 4. Ethical Framework

Per MARSYS-JIS Ethical Framework (MACRO_PLAN_v2_0.md): the instrument produces probabilistic, calibrated, auditable outputs for consenting audiences under stated disclosure tiers. It is not a fortune-telling product. This tier enforces that boundary by redacting personal data.
