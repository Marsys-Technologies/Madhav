# 03_DOMAIN_REPORTS — Instructions

Nine domain reports (career, children, financial, health, parents, psychology, relationships, spiritual, travel) plus a whole-chart synthesis. Each is a lens on the whole-chart synthesis, never a substitute for it.

- The highest version of each report is current (e.g. `REPORT_FINANCIAL_v2_1.md`, the other `_v1_1` files); older versions are retained for audit.
- Every report cites its parent synthesis version, carries a Cross-Domain Linkages section, and flags-and-resolves any contradiction with the synthesis rather than silently diverging.
- Present chart signals with valence-neutral framing, then invite goal-formation.
